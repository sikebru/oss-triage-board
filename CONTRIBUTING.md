# Contributing

Thanks for considering a contribution to OSS Triage Board.

## Before starting

1. Check existing issues and pull requests for related work.
2. For a substantial change, open an issue first to discuss the approach.
3. Keep changes focused and explain the user problem they solve.

## Development

This is a static HTML, CSS, and JavaScript project. There is no package installation or build step.

1. Fork the repository.
2. Create a branch for your change.
3. Open `index.html` through a local static server.
4. Test with at least one public repository with issues and pull requests.
5. Test an invalid repository and a repository with no open items.
6. Check the browser console for errors.
7. Open a pull request describing the change and how you tested it.

## Contribution expectations

- Do not add secrets, personal access tokens, or private repository data.
- Do not introduce write operations against GitHub without a separate design discussion and explicit maintainer approval.
- Keep privacy and read-only behavior as defaults.
- Update README and ROADMAP when behavior changes.
- Be respectful and constructive in discussions.
