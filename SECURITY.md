# Security Policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not publish credentials, tokens, or sensitive personal data in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer privately before disclosing details.

## Security design

- The current app is read-only.
- It does not request GitHub credentials.
- It does not execute repository code.
- It does not send entered repository names to an OSS Triage Board backend.
- Do not enter secrets or private repository URLs.
