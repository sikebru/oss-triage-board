# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Examples of behavior that contributes to a positive environment include being considerate, accepting constructive criticism, focusing on what is best for the community, and showing empathy toward other contributors.

Unacceptable behavior includes harassment, insults, discriminatory language, doxxing, and publishing private information without permission.

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject contributions that do not align with this Code of Conduct.

This Code of Conduct applies in project spaces and when someone is representing the project in public spaces.
